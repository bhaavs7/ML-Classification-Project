# Machine Learning Classification Project

## Overview

This project demonstrates four supervised machine learning
classification algorithms using real-world datasets.

## Algorithms Used

1. Random Forest
2. Logistic Regression
3. XGBoost
4. Decision Tree

## Datasets

### Breast Cancer Dataset

Used with Random Forest to classify breast cancer samples.

### Pima Indians Diabetes Dataset

Used with Logistic Regression and Decision Tree to predict diabetes outcomes.

### Titanic Dataset

Used with XGBoost to predict passenger survival.

## Evaluation Metrics

The models are evaluated using:

- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix
- ROC-AUC
